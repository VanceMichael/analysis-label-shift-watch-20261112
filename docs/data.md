# 数据与口径

truth 允许空字符串表示无标签；scoreA+scoreB 为一，classifier 标识冻结分类器。

`data/records.json` 是版本为 1 的演练数据，所有人员、机构、商品和交易均为本地合成记录。`id` 是导入记录键，不自动代表企业、访问或其他统计单位；记录键不得重复。数值字段必须有限，整数字段不得超过安全整数范围。空字符串可用于字段约定允许的未公开标签，不用零冒充缺测。

| 字段 | 类型 |
| --- | --- |
| `id` | `string` |
| `sample` | `string` |
| `partition` | `string` |
| `truth` | `string` |
| `scoreA` | `number` |
| `scoreB` | `number` |
| `visible` | `integer` |
| `classifier` | `string` |

现有 `summary` 按 `partition` 清点记录，`sum` 为 `scoreA` 的逐行核对值，不代表统计推断或跨期业务指标。分组按键排序，行按记录键稳定处理。`data/expected-summary.json` 是独立生成的现有核算对照。

`inspect` 返回输入行数、字段列表与 SHA-256 指纹；指纹不依赖字段或记录排列。数据版本不支持时应直接拒绝，不做静默迁移。错误发生时命令返回非零退出码。

## 分区与角色

`data/policy.json` 的 `partitionRoles` 把分区名映射到四个角色：

| 角色 | 默认分区 | 用途 |
| --- | --- | --- |
| `training` | `training` | 训练数据；**从不**进入迁移估计 |
| `source` | `source` | 源地区带真值的验证集；估计混淆/软混淆算子 |
| `target` | `target` | 目标地区未标注分数；只提供分数边缘分布 |
| `review` | `review` | 延迟审阅集；只可在公开时点之后作事后检查 |

`shift` 保存诊断阈值（残差、条件数、支撑外比例、区间宽度、样本量下限、重采样次数、置信水平与 `zeroPriorTolerance`），省略时使用代码内默认值。`reviewRelease` 是审阅集公开时点，与数据中的 `asOf` 比较；未到该时点时审阅集不参与任何估计或检查。

## 迁移诊断口径

`migrate` 在标签迁移假设下估计目标类别比例：

- 源验证集带真值记录估计软混淆算子 `C[k][j] = E[score_k | truth=j]`，另报多数票硬算子作对照。
- 目标批次只用 `scoreA/scoreB`；有真值也不参与估计、校正或参数选择，只记 `target-labels-ignored` 诊断。
- 先验在单纯形上求解 `min ||C*pi - q||^2`，约束为非负且和为一；解落在边界时显式记录零先验类别，**不**把无约束逆矩阵的负值裁零。
- 可识别时才按先验比修正后验分数并逐行归一，同时报告未校正与校正的后验质量和硬计数；目标无真值，不声称准确率提高。
- 源验证集与目标集分别重采样给出先验区间，随机数只来自策略中的 `seed`。
- 不可识别时停用校正并保留停用理由：源类别为空、算子秩亏损/病态、目标分布超出源条件支撑、边缘残差超限、重加权后仍见条件漂移。
- `data/scenarios/` 提供合成情形：可手算二分类、几乎相同类别分数、目标新类别、目标条件分布变化、零先验。
